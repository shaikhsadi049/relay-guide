# Relay — user guide

The complete user guide for **Relay**, a fully automated XAUUSD expert advisor for
MetaTrader 5.

- **Read it online:** open `index.html` — it shows the guide in the page and links
  the download.
- **Download it:** [Relay_User_Guide.pdf](Relay_User_Guide.pdf) — for offline
  reading and printing.

One position at a time, a stop loss on every trade from the moment it opens, no
grid and no martingale. Three engines for trend, fast and quiet markets, and a prop
firm mode that takes your firm's limits in the firm's own terms.

Questions and bug reports: **shaikhsadi049@gmail.com** — please include your broker,
your account type and the terminal's log for the day in question.
